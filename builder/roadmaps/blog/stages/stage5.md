Let authors format posts with Markdown.

- Render post bodies as Markdown on the post page, using the `mdlite` library (see its documentation below). For example, `**bold**` should appear as bold text.
- Add a `requirements.txt` file listing every library the app needs, one per line, pinning mdlite (for example `mdlite==1.0.0`).

Keep every existing feature working.
