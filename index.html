How this works (start here)

Builder builds a pretend website in stages and only cares about features. Every new page starts with no security.

Attacker (red team) learns by trial and error: each attack gives it a reward (a breach is +10, a failed try −0.5). Over time it learns which attacks work on which kinds of page. Every breach is reported.

Defender (blue team) reads each report and has to guess the right fix. Some fixes sound right but don't work. The Attacker retests every fix, so the Defender learns which fixes are real. When a fix keeps working, it becomes a rule the Builder follows on new pages.

Nothing here is real hacking. Each weakness is a simple rule. Click any attack name to learn what it is and how it's fixed, or click a page on the site map to see its security settings.
